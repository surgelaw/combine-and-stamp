## 💡 Key Decisions Made

### 1. Async Page Count Loading
**Decision:** Load page counts in background thread  
**Rationale:** Don't block UI for large files  
**Result:** Smooth performance even with many files

### 2. Reorderable by Default
**Decision:** Always show reorderable list (not a toggle)  
**Rationale:** Simpler UX, always available  
**Result:** Clean interface, no mode switching

### 3. Position Numbers in Circles
**Decision:** Show position as colored circles  
**Rationale:** Clear visual indicator of order  
**Result:** Professional appearance, easy to scan

## 🎯 The Three v1.1 Features

### Feature F-01: Drag-and-Drop Interface ⭐ START HERE
**What:** Users can drag PDF/image files into the app instead of right-clicking in Finder  
**Why:** Faster, more intuitive workflow  
**Effort:** 3-4 days  

**Key Components to Build:**
- `DropZoneView.swift` - The drop target
- `FileListView.swift` - Display selected files
- `FileValidator.swift` - Validate file types

### Feature F-02: Drag-and-Drop Reordering
**What:** Users can reorder files before combining them  
**Why:** Fixes the #1 user complaint (wrong merge order)  
**Effort:** 3-4 days  

**Key Components to Build:**
- `ReorderableFileListView.swift` - List with drag-to-reorder
- `FileRowView.swift` - Individual row with position number

### Feature F-03: Presets and Profiles
**What:** Save and reuse common settings (prefix, numbering, etc.)  
**Why:** Eliminates repetitive setup for common tasks  
**Effort:** 4-5 days  

**Key Components to Build:**
- `StampPreset.swift` - Data model
- `PresetManager.swift` - Save/load/import/export
- `PresetPickerView.swift` - UI for selecting presets
- App Groups for sharing between app and extension

## 🔧 Key Configuration Changes

### 1. Enable App Groups
Both targets need App Groups capability:
- Group ID: `group.com.company.pdfcombinestamp`
- Purpose: Share presets between main app and extension

### 2. Update Entitlements
Add to both `.entitlements` files:
```xml
<key>com.apple.security.application-groups</key>
<array>
    <string>group.com.company.pdfcombinestamp</string>
</array>
```

### 3. File Organization
Create new groups in Xcode:
- `Models/`
- `Managers/`
- `Views/MainApp/`
- `Views/Shared/`
- `Utilities/`

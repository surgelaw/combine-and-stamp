## 🎯 Core Features

### 1. Drag-and-Drop Interface (F-01)
**What:** Replace Finder-first workflow with in-app drop zone  
**Why:** Faster workflow, more intuitive  
**User Story:** As a user, I want to drag files directly into the app instead of right-clicking in Finder

**Key Components:**
- `DropZoneView.swift` - Main drop target
- `FileListView.swift` - Show selected files
- `MainProcessingView.swift` - Orchestrate flow

**Acceptance:**
- ✅ Drag PDFs/images into app
- ✅ Invalid files rejected with clear error
- ✅ Processing works same as Quick Action
- ✅ Works from any accessible location

---

### 2. Drag-and-Drop Reordering (F-02)
**What:** Let users reorder files before combining  
**Why:** Fixes #1 user complaint (wrong merge order)  
**User Story:** As a user, I want to reorder files so they combine in the correct order

**Key Components:**
- `ReorderableFileListView.swift` - Drag-to-reorder list
- `FileRowView.swift` - Individual row with drag handle

**Acceptance:**
- ✅ Drag files to reorder
- ✅ Visual feedback during drag
- ✅ Order preserved in output
- ✅ Works in app and extension
- ✅ Keyboard accessible

---

### 3. Presets and Profiles (F-03)
**What:** Save reusable templates for settings  
**Why:** Eliminates repetitive setup  
**User Story:** As a user, I want to save my common settings so I don't have to re-enter them every time

**Key Components:**
- `PresetManager.swift` - CRUD operations
- `PresetPickerView.swift` - Select preset
- `PresetEditorView.swift` - Create/edit preset
- Import/Export JSON functionality

**Acceptance:**
- ✅ Save settings as named preset
- ✅ Select preset to auto-populate
- ✅ Edit/delete presets
- ✅ Persist across launches
- ✅ Export/import JSON
- ✅ Works in app and extension

## 🎯 Success Criteria

### Must Have (v1.1 Release Blockers)
- ✅ Drag-and-drop works for PDF and image files
- ✅ File reordering works and persists through processing
- ✅ Presets can be created, saved, loaded, and applied
- ✅ Presets can be exported and imported as JSON
- ✅ All features work in both main app and extension
- ✅ No critical bugs
- ✅ No regressions from v1.0

## 📞 Quick Commands

### Development
```bash
# Open project
open PDFCombineStamp.xcodeproj

# Build
./build.sh --clean

# Test extension
./test_extension.sh
```

### Testing
```bash
# Run unit tests
xcodebuild test -scheme PDFCombineStamp

# Check extension registration
pluginkit -m -v | grep PDFCombineStamp

# Reset extension cache
/System/Library/CoreServices/pbs -flush && killall Finder
```

### Debugging
```bash
# Check UserDefaults (presets)
defaults read group.com.company.pdfcombinestamp

# Clear presets (for testing)
defaults delete group.com.company.pdfcombinestamp savedPresets

# View logs
log show --predicate 'process == "PDFCombineStamp"' --last 1h
```
